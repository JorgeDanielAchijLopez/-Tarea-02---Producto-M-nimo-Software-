# Shell Fuel Control 
 
Producto mínimo de software Backend-Frontend desarrollado para la gestión y monitoreo de ventas e inventario de combustible. 
 
## Empresa seleccionada 
 
Shell 
 
## Objetivo 
 
Desarrollar una aplicación web que permita administrar información básica relacionada con estaciones, productos, ventas e inventario de combustible. 
 
El sistema contará con un backend encargado del procesamiento de la información, un frontend para la interacción con el usuario y una base de datos para almacenar los registros generados. 
 
## Funcionalidades previstas 
 
- Gestión de estaciones. 
- Gestión de productos y combustibles. 
- Registro de ventas. 
- Control de inventario. 
- Consulta del historial de ventas. 
- Dashboard con indicadores generales. 
- Alertas de inventario bajo. 
- Análisis de datos mediante Power BI.
